# Dynamic eQTL

Scripts for the dynamic eQTL analysis. Run in order:

| Script | Description |
| --- | --- |
| `01.dynamic_eQTL_test.R` | Test for dynamic eQTLs |
| `02.plot.R` | Visualize dynamic eQTL results |
| `03.sat_vat_intersect_dynamic_cis_beta_heatmap.R` | Heatmap of cis effect sizes for dynamic eQTLs shared between SAT and VAT |
